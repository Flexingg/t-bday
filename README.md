# 🎂 The Impossible Birthday Quiz (T-Bday Edition + ETERNAL MODE)

A high-polish, self-hosted web game inspired by *The Impossible Quiz*. Tailored as a special birthday challenge for **T**, featuring 100 mind-bending, bizarre, and crazy hard trivia levels across two epic modes!

---

## 🎮 Game Modes

### 1. 🎂 Classic Birthday Quiz (Levels 1 - 30)
- **3 Lives System (❤️ ❤️ ❤️):** 3 strikes and you're out.
- **Grand Prize Reveal at Level 30:** Cracking the Titanium Vault at Level 30 triggers victory fanfare, confetti rain, and reveals the real birthday gift location:
  ```
  its under Rhodes mattress
  ```

### 2. 🔥 ETERNAL MODE (Levels 31 - 100) — SUDDEN DEATH
- **70 Additional Brutal Trivia Questions:** Deep astrophysics, bizarre biology, quantum paradoxes, macabre history, and extreme linguistics.
- **ZERO LIVES / SUDDEN DEATH:** Any single wrong answer or timer expiry = instant elimination!
- **Legendary Level 100 God Vault:** Crack the God Equation `(42 × 6) + 365 = 617` to achieve the title of **Eternal Deity of Trivia**!

---

## 🚀 Running via Docker Compose

```powershell
cd C:\RandallEngineering\T-Bday
docker compose up -d --build
```
Open **[http://localhost:8080](http://localhost:8080)** in your web browser.

---

## 🛠️ Testing & Dev Controls
- **Dev Skip:** Press `Shift + N` anywhere in the quiz to advance to the next question instantly.
- **Direct Mode Selection:** Choose between Classic (1-30) or Eternal (31-100) right from the start screen, or naturally transition into Eternal Mode after clearing Level 30!
