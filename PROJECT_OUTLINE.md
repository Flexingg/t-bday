# 🎂 T-Bday: The Impossible Birthday Quiz (Crazy Hard Trivia Edition)

> A high-polish, self-hosted web game inspired by *The Impossible Quiz*. Featuring 30 mind-bending, bizarre, and incredibly difficult trivia levels concluding with the secret reward reveal at Level 30.

---

## 🎯 1. Overview & Core Features
- **3 Lives System (❤️ ❤️ ❤️):** 3 mistakes lead to a humorous Game Over roast and quick retry.
- **Bomb Timers (💣 8-10s):** High-stakes rapid defusal countdowns with ticking audio and panic warnings.
- **Stand-alone Web Audio API:** 100% synthesized sound effects (buzzers, boings, pops, fanfare, explosions, chimes) with zero external MP3 dependencies.
- **Grand Finale Reward:** Cracking Level 30 opens the titanium vault and reveals:
  ```
  its under Rhodes mattress
  ```
